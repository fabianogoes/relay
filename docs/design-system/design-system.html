Externo

O host escreve o script wrapper e pede ao emulador que o abra. O script é o contrato, não a linha de comando.

echo $$ > "$RUN/pid"
"<bin>" "<argv...>"
echo $? > "$RUN/exit"

PID e exit code vêm do próprio script, não do emulador.
